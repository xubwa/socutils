# Stage 1 一页总结

**对上了**
- NR 锚点：ΔE_l → −(45/256)(l+½)⁻⁴[1 − (5/4)(l+½)⁻²]（l=29：p_l = 3.997）；聚合点 cusp 0.498（Kato 1/2）。
- c→∞ 锚点（quad）：c/Z = 137036 时增量 = NR（≤4×10⁻⁹）且偏差严格 ∝ (Zα)²；
  c/Z = 1370 时 (l+½)²d_l/(Zα)² → 3/64（0.1–0.2%），即 Kutzelnigg 2008 系数（以 ψ₀ 代入）。
- quad/double 在物理 Z 一致到 3×10⁻¹³；三套径向网格对相对论位移一致到 ≤2×10⁻³。
- 一个无参数的短程模型（自由 no-pair 相对运动）同时给出 α²(l+½)⁻²（DPT）与 (Zα/4π) ln r12；
  LL 通道能量尾 −Zα/(16π)(l+½)⁻³ 与数值差 1%，聚合点振幅 Z=30 时差 0.3%。

**没对上 / 发现的问题**
- 自己的推导错误一次（把 Chebyshev 展开当 Legendre，系数差 4/3），已用精确积分改正。
- nb=360 网格在 Z=80（点核）变分坍塌（quad 同样），已排除并加入自动 1s 检查。
- Z ≥ 50 时模型振幅偏低 3–10%（∝ (Zα)²），来源（1s 小分量源项）是推断，未单独验证；LS/SS 尾系数只有拟合值。

**与文献的关系（需要你判断，见对话）**
- 数值显示 no-pair（Furry）投影后 ν = +α/(4π)，对 α 线性；Li/Shao/Liu 2012 对未投影 DC 给 ν = O(α²) < 0，
  并据此（Liu 2014）建议直接用非相对论 STG。我们的结果在 Z=80、L=5 时相对论 (l+½)⁻³ 尾与 NR 尾同量级，
  这与"奇点可忽略"的实践结论有冲突（不是与其数学结论冲突：哈密顿量不同）。
