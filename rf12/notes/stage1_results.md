# Stage 1：He 样离子 Dirac–Coulomb no-pair 一阶对函数的聚合行为（数值检验）

标注：**[数值]** = 本代码计算并经收敛/交叉检验的结果；**[推断]** = 模型或推导，已用数值检验但不是定理；
**[文献]** 见 `stage0_literature.md`。

## 0. 计算的是什么（brute-force reference）

- 对象：1s½² (J=0) He 样离子在 1/Z 展开下的二阶能量 E2 = Σ_l ΔE_l 及一阶对函数 u。
  零阶 = 类氢 Dirac（点核），微扰 = 1/r12（Coulomb，无 Breit），**no-pair = 裸核 Furry 投影**
  （只对正能态求和，单激发 1s→ns 包括在内，这是类氢 E2 的定义）。
  标度单位（r→Zr，E→E/Z²）下核电荷为 1、光速为 c/Z，所以 E2 只依赖 Zα；
  非相对论极限 E2 = −0.1576664 Eh，Schwartz 公式 ΔE_l = −(45/256)(l+½)⁻⁴[1 − (5/4)(l+½)⁻² + …]。
- 径向：B 样条 + dual kinetic balance（Shabaev 2004），分段几何节点（h/r 为常数，匹配对函数在 r1−r2 方向 ~r/l 的宽度）；
  分波 l = 虚轨道大分量的 l（κ = l 与 −(l+1) 求和）。
- 角动量：在非耦合 (m_r, m_s) 表象中直接用 3j 计算 ⟨rs||ab⟩，不依赖任何重耦合公式；
  检验：jj 权重 W(l−½)+W(l+½) = 2/(2l+1)（非相对论的 1/(2l+1)）到机器精度。
- Coulomb 积分只插值 ρ（从不插值 s^l），对 B 样条在 [0, rmin] 上精确，避免 x^−(l+1) 放大误差。
- 精度：同一套代码有 double 与 quad（IEEE binary128，libquadmath）两个后端；quad 本征求解器为
  Householder + 隐式 QL（`lib/rf12/qlinalg.c`）。quad 对 c/Z ≫ 1 是必需的：本征值中含 2c² ≈ 2×10¹⁰ 的项，double 丢失约 10 位。
- 代码：`socutils/rf12/`（bspline, pairpw, angular, xp, relmodel），驱动与分析 `examples/rf12/stage1_*.py`，单元测试 `rf12/test/test_rf12.py`。

### 2a. 小 l（l ≲ 1/(Zα)）：Kutzelnigg 2008 的 α²(l+½)⁻² 律成立 [数值]
Z=2 在 l=4–5 处 (l+½)²d_l/(Zα)² = 0.0456，接近把 ψ₀ 代入 Kutzelnigg 2008 系数得到的 **3/64 = 0.0469**（符号为正）。
但即使对 Z=2，这个比值也随 l 单调下降（l=20 时 0.0375），局部指数从 2 漂向更大，说明 (l+½)⁻² 律只是中间渐近。
§5 的 quad 锚点（c/Z = 1370）在纯 DPT 区检验 3/64。

### 2b. 大 l（l ≳ 1/(Zα)）：(l+½)⁻² 律失效，ΔE_l 变为 ∝ −Zα(l+½)⁻³ [数值]
- d_l 在 l ≈ 18 (Z=30)、10 (Z=50)、5 (Z=80) 处由正变负；总增量的局部指数在 l=29 处为 3.45/3.26/3.14，并继续向 3 下降。
- 按分量通道拆分 E2（LL·LL、LS·LS、SS·SS，严格求和等于总值）：
  - **LL 通道（扣除 NR）**：A3 = −(0.0197 ± 0.0002)·Zα，在 Z=30/50/80 上与 Z 无关，即对 Zα 是**线性**的。
  - LS 与 SS 通道在所有 l 上都已是纯 (l+½)⁻³（来自小分量的 kinetic-balance 结构），系数 ≈ −0.016(Zα)³ 与 −0.005(Zα)³。
  - 合计：ΔE_l → −Zα[0.0197 + ~0.022(Zα)²](l+½)⁻³（拟合描述，非解析）。

### 2c. 局部行为：u 在 r12 → 0 处是对数，不是 cusp [数值 + 推断]
- 聚合点分波振幅 a_l(r,r) 的衰减指数：NR 为 2（r12 cusp）；DC no-pair 在 Z=80 处 LL/SS/LS 分别为 1.17/1.07/1.08 且继续向 **1** 下降。
  a_l ~ (l+½)⁻¹ 对应 ln r12（ln r12 的 Legendre 系数为 −(2l+1)/(2l(l+1))）。
- 无参数短程模型 [推断]：两个自由电子、各自乘以自由正能投影的 LL 块、除以相对运动动能，
  ũ(q) = −(4π/q⁴)·g(q/c′)·Φ₀(r,r)，g(x) = [(1+1/√(1+x²))/2]²·(√(1+x²)+1)/2，c′ = c/Z。
  - g → 1：Kato cusp r12/2；
  - 展开到 O(1/c′²)：u ∋ +1/(4c′² r12)，其分波能量尾**精确等于** Kutzelnigg 2008 的 2π²α²∫|ψ(r,r)|²r³dr·(l+½)⁻²；
  - g → x/8（q ≫ c′）：u ∋ (Zα/4π)·ln r12·Φ₀（标度单位）。
- 模型 vs 计算（LL 自旋单态分波，r=1，l=29，无任何拟合参数）：Z=10 0.996（≈ NR 基组极限 0.996），Z=30 1.003，Z=50 1.027，Z=80 1.095；
  在 Z=80、l=20 处对 r2 ∈ [0.8, 1.2] 的非对角 u_l(1, r2) 比值同样均匀地在 1.07–1.11 之间（不存在被 r1=r2 探针遗漏的各向异性）。
  偏差 ∝ (Zα)²，来源推测为模型忽略的 1s 小分量。
- 能量尾：纯 Φ₀·L ln r12 的分波能量精确渐近为 −(32π²/3)L∫r⁴|Φ₀(r,r)|²dr·(l+½)⁻³ = −L/4·(l+½)⁻³（已用精确 Legendre 系数在 l = 10…80 数值验证）。
  代入 L = Zα/(4π)：**ΔE_l^LL → −Zα/(16π)·(l+½)⁻³ = −0.019894·Zα·(l+½)⁻³**，与 LL 通道拟合值 −0.0197·Zα 差 1%。
  （更正说明：我最初误用了 ½ln(1−2tx+t²) = −Σ(t^l/l)P_l（那是 Chebyshev 展开），得到 3/(64π)，偏小 4/3；已改正。）

## 3. 物理解读（换回非标度单位）[推断，由 §2 数值支持]
一阶 no-pair DC 对函数在电子聚合处有三个区域（ψ 为全波函数，Φ 为其在聚合点的值）：
1. r12 ≫ α a₀：Kato cusp ψ ≈ Φ(1 + r12/2)，相对论修正为 +α²/(4 r12)（DPT），给出 (3/64)(Zα)²(l+½)⁻² 尾（He 样一阶）。
2. r12 ≲ α a₀ ≈ 0.0073 bohr（与 Z 无关）：ψ ≈ Φ(1 + (α/4π) ln r12 + …)，即 **ψ ~ r12^ν，ν = +α/(4π)**（对 α 线性、为正：波函数在聚合点被压低）。
   这与 Kutzelnigg 1989 摘要中"free-particle no-pair 投影的算符 ν 对 Z/c 线性"的说法一致；
   与 Li/Shao/Liu 2012 对**未投影** DC 给出的 ν = O(α²)、ν<0 不同——差别来自 no-pair 投影本身。
3. 交叉在 l ≈ 1/(Zα) 处（分波分辨 r12 ~ r/l，r ~ 1/Z）：Z=80 时 l ≈ 2，Z=10 时 l ≈ 14，Z=2 时 l ≈ 70。
   注意：ν 是一阶微扰结果（O(α)）；更高阶修正未计算。

## 4. 对 correlation factor 的含义 [推断]
- 在 parent theory（DC no-pair, Furry）里，单态 LL 关联因子的"正确"短程形状是 ũ(q) ∝ g(q/c)/q⁴ 的傅里叶变换 h(r12; c)：
  一个只依赖 c·r12 的普适函数，NR 极限为 r12/2，短程为 (α/4π) ln r12。非相对论 STG 只能复现第 1 区。
- 能量后果：截断在 L 时，(l+½)⁻³ 尾留下 ≈ 0.0199·Zα/(2L²)（E2 单位，Eh），而 NR 尾为 (45/256)/(3L³)。
  Z=80、L=5：相对论尾 ≈ 2.3×10⁻⁴，NR 尾 ≈ 4.7×10⁻⁴，二者同量级——对重元素，只修正 r12 cusp 的 F12 会留下可观的残余。
- 小分量：LS、SS 通道各自有纯 (l+½)⁻³ 尾，系数 ∝ (Zα)³（Z=80 时约占 LL 尾的 40%），
  需要 kinetic-balance 型的几何子（Stage 0 中的三种方案在这里可以被数值区分）。
- 这些结论依赖于投影算符的选择（Furry/裸核）；换成 DHF Furry 或 extended no-pair 投影时短程结构应相同（高动量下都趋于自由投影），未计算。
